# Adblock-bot

Et lite nettleserspill om dagens surfeopplevelse. Du er en bot som samler inn data på nettsider, skyter ned trackere, reklamemonstre og reklameflater, og klikker bort pop-ups før nettleseren krasjer.

Spill: https://adblock.kyuubi.no

Laget av Kyuubi Creative.

## Teknisk

- Alt ligger i én fil: `index.html` (HTML, CSS og JavaScript, ingen byggesteg).
- Logoene til egne merkevarer ligger inline som data-URI-er.
- Publiseres med GitHub Pages fra `main`. Domenet settes i `CNAME`.
